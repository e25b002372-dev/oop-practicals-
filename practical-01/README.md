# Practical 01: Student result

A C++17 program reads a student's name and two integer marks, calculates their average, and checks whether both marks meet the pass mark of 40.

## Compile and run
From the directory containing main.cpp, run:

```sh
g++ -std=c++17 -Wall -Wextra main.cpp -o result
./result
```
On Windows PowerShell, use `.\result.exe` for the last command.

## Sample session
```text
Student name: Asha Patil
Enter two test marks (0 to 100): 72 65
Student: Asha Patil
Marks: 72, 65
Average: 68.5
Result: Pass
```
